# Verdct Landing Page

Static landing page for Verdct — verdct.org

## Deploy to Vercel

1. Push this folder to a GitHub repository
2. Go to vercel.com and import the repository
3. Vercel auto-detects static HTML — click Deploy
4. Add your custom domain (verdct.org) in Vercel project settings

## Files

- `index.html` — the full landing page (self-contained, no dependencies)
- `vercel.json` — Vercel deployment config

## To update the site

Edit `index.html`, commit and push to GitHub — Vercel redeploys automatically.

## When App Store link is ready

In `index.html`, search for `https://apps.apple.com` and replace with your real App Store URL.
